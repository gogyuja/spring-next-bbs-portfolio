## 1. 개요

카카오·구글 소셜 계정으로 로그인. 최초 로그인 시 자동 회원가입 처리.
BE-driven OAuth 방식: Spring Security 6가 OAuth 전체 플로우를 담당.

---

## 2. 전체 아키텍처 & 데이터 플로우

```
[FE 로그인 페이지]
  카카오/구글 버튼 클릭
      ↓
GET  BE /oauth2/authorization/{provider}    ← Spring Security 처리
      ↓
소셜 로그인 페이지 (카카오/구글 서버)
      ↓
GET  BE /login/oauth2/code/{provider}       ← 소셜 콜백
      ↓
CustomOAuth2UserService
  - provider + provider_id 로 User 조회
  - 없으면 신규 생성 (닉네임: User-{UUID 앞 8자리})
  - 로그인 차단 여부 확인 → 차단 시 에러 리다이렉트
      ↓
OAuth2LoginSuccessHandler
  - Access Token  생성 (30분, JWT)
  - Refresh Token 생성 (7일, JWT)
    → Redis 저장: key=RT:{userId}, value=refreshToken, TTL=7일
    → HttpOnly 쿠키: refresh_token, Path=/, MaxAge=604800, SameSite=Lax
  - FE로 리다이렉트: {FE_URL}/auth/callback?accessToken={AT}
      ↓
[FE /auth/callback 페이지]
  - URL searchParams에서 accessToken 추출
  - Zustand AuthStore에 저장 (메모리)
  - router.replace('/')
```

### 토큰 전략

| 토큰 | 수명 | 저장 위치 |
|---|---|---|
| Access Token | 30분 | FE 메모리 (Zustand) |
| Refresh Token | 7일 | Redis + HttpOnly 쿠키 |

### 4.3 User 엔티티 (Flyway V1)

```sql
CREATE TABLE users (
  id              BIGINT AUTO_INCREMENT PRIMARY KEY,
  provider        VARCHAR(20)   NOT NULL COMMENT 'KAKAO | GOOGLE',
  provider_id     VARCHAR(100)  NOT NULL,
  nickname        VARCHAR(50)   NOT NULL,
  profile_image   VARCHAR(500),
  role            VARCHAR(20)   NOT NULL DEFAULT 'USER' COMMENT 'USER | MANAGER | ADMIN',
  banned_at       DATETIME,
  ban_expires_at  DATETIME,
  deleted_at      DATETIME,
  created_at      DATETIME      NOT NULL,
  updated_at      DATETIME      NOT NULL,
  UNIQUE KEY uq_provider (provider, provider_id)
);
```

### 4.4 SecurityConfig 핵심

```
- /oauth2/authorization/**   → permitAll
- /login/oauth2/code/**      → Spring Security 처리
- /api/auth/**               → permitAll (logout, reissue)
- 나머지 /api/**             → authenticated (JWT 필터 추후 추가)
- Session: STATELESS
- CORS: FE origin 허용
- oauth2Login: userInfoEndpoint → CustomOAuth2UserService
             successHandler    → OAuth2LoginSuccessHandler
             failureHandler    → OAuth2LoginFailureHandler
```

### 4.5 CustomOAuth2UserService

```
1. OAuth2UserRequest에서 registrationId 추출 (kakao / google)
2. provider별 attribute 정규화 → OAuth2UserInfo {provider, providerId, nickname, profileImage}
3. UserRepository.findByProviderAndProviderId() 조회
4. 없으면 User.create() 신규 저장
   - nickname: "User-" + UUID.randomUUID().toString().substring(0, 8)
   - profileImage: null (기본 이미지는 FE에서 처리)
5. 로그인 차단 확인: banExpiresAt != null && banExpiresAt.isAfter(now)
   → 차단 시 OAuth2AuthenticationException 발생
6. CustomUserDetails(user) 반환
```

### 4.6 OAuth2LoginSuccessHandler

```
1. CustomUserDetails에서 User 추출
2. JwtUtil.generateAccessToken(userId, role)  → 30분
3. JwtUtil.generateRefreshToken(userId)       → 7일
4. Redis: SET RT:{userId} {refreshToken} EX 604800
5. HttpOnly 쿠키 Set:
   name=refresh_token, value={RT}, httpOnly=true,
   secure=false(로컬)/true(prod), path=/, maxAge=604800, sameSite=Lax
6. 302 redirect → {frontend.url}/auth/callback?accessToken={AT}
```

### 4.7 JwtUtil

```
- generateAccessToken(Long userId, String role) → String
- generateRefreshToken(Long userId)             → String
- validateToken(String token)                   → boolean
- extractUserId(String token)                   → Long
- extractRole(String token)                     → String
```

### 4.8 환경 변수 (application.yml)

```yaml
spring:
  security:
    oauth2:
      client:
        registration:
          kakao:
            client-id: ${KAKAO_CLIENT_ID:YOUR_KAKAO_CLIENT_ID}
            client-secret: ${KAKAO_CLIENT_SECRET:YOUR_KAKAO_CLIENT_SECRET}
            redirect-uri: "{baseUrl}/login/oauth2/code/kakao"
            authorization-grant-type: authorization_code
            scope: profile_nickname, profile_image
          google:
            client-id: ${GOOGLE_CLIENT_ID:YOUR_GOOGLE_CLIENT_ID}
            client-secret: ${GOOGLE_CLIENT_SECRET:YOUR_GOOGLE_CLIENT_SECRET}
            redirect-uri: "{baseUrl}/login/oauth2/code/google"
            scope: profile, email
        provider:
          kakao:
            authorization-uri: https://kauth.kakao.com/oauth/authorize
            token-uri: https://kauth.kakao.com/oauth/token
            user-info-uri: https://kapi.kakao.com/v2/user/me
            user-name-attribute: id

jwt:
  secret: ${JWT_SECRET:your-256-bit-secret-key-here-minimum-32chars}
  access-token-expiry: 1800000    # 30분 (ms)
  refresh-token-expiry: 604800000 # 7일 (ms)

frontend:
  url: ${FRONTEND_URL:http://localhost:3000}
```

### 5.3 AuthStore (Zustand)

```typescript
interface AuthState {
  accessToken: string | null;
  userId: number | null;
  role: string | null;
  setAuth: (token: string) => void;  // JWT 디코딩해서 userId, role 추출
  clearAuth: () => void;
}
```

### 5.4 로그인 페이지 (`/login`)

```
- 카카오 버튼: href={NEXT_PUBLIC_API_URL}/oauth2/authorization/kakao
- 구글 버튼:   href={NEXT_PUBLIC_API_URL}/oauth2/authorization/google
- 'use client' 불필요 — 단순 링크
```

### 5.5 Callback 페이지 (`/auth/callback`)

```
'use client'
1. useSearchParams()로 accessToken 추출
2. accessToken 없으면 /login으로 이동
3. authStore.setAuth(accessToken) 호출
4. router.replace('/')
```

### 5.6 Axios 인스턴스

```typescript
// lib/axios.ts
- baseURL: NEXT_PUBLIC_API_URL
- withCredentials: true  (HttpOnly 쿠키 자동 전송)
- 요청 인터셉터: authStore에서 accessToken 읽어 Authorization: Bearer {token} 헤더 첨부
```
